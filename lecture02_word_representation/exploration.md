# 探索：CBOW/Skip-Gram 的问题与解决

CBOW 和 Skip-Gram 是词表示学习的关键起点，但它们不是终点。它们把词从离散符号变成向量，却仍然受限于静态词表、局部窗口和浅层目标函数。

## 主要问题

| 问题 | 表现 | 根因 |
|---|---|---|
| 完整 softmax 代价高 | 词表大时每步都要计算全部词概率 | 输出层复杂度为 $O(V)$ |
| 高频词支配训练 | “的、是、the”等词出现过多 | 共现频率不等于语义信息量 |
| 数据稀疏 | 低频词向量不稳定 | 低频词上下文样本不足 |
| OOV | 未登录词没有向量 | 词被当作不可拆分原子 |
| 一词多义 | “bank”只有一个向量 | 静态词向量不随上下文改变 |
| 长距离依赖弱 | 只能看固定窗口 | 局部窗口无法覆盖篇章线索 |
| 词序信息弱 | CBOW 平均上下文词 | 平均池化丢失顺序和句法 |
| 负采样偏差 | 采样词影响训练方向 | 目标函数变成近似判别任务 |

## 解决路径

### 1. 训练效率：negative sampling 与 hierarchical softmax

完整 softmax 要对全词表归一化：

$$
p(w\mid h)=\frac{\exp(u_w^\top h)}{\sum_{v=1}^{V}\exp(u_v^\top h)}
$$

negative sampling 把多分类改成二分类：真实中心词是正样本，从噪声分布采几个负样本，让模型区分“真实共现”和“随机拼接”。它降低计算成本，也让训练更像局部对比学习。

hierarchical softmax 用 Huffman 树把一次 $V$ 类预测变成路径上的若干二分类，复杂度从 $O(V)$ 降到 $O(\log V)$。

### 2. 高频词控制：subsampling 与重加权

对高频词随机下采样，减少它们对训练的支配。直觉是：看到一次“的”提供的信息远少于看到一次专业实体或动词。也可以用 tf-idf、shifted PMI 或 GloVe 式全局共现重加权，把“出现次数”转成“信息贡献”。

### 3. OOV 与形态信息：subword 表示

fastText 把词拆成字符 n-gram，例如：

```text
where -> <wh, whe, her, ere, re>
```

词向量由子词向量组合得到。这样新词即使没见过，只要字符片段见过，也能得到近似表示。对中文也可引入字、偏旁、拼音、词片段等多粒度信息。

### 4. 多义词：从静态向量到上下文化向量

静态词向量的问题是：

```text
苹果 发布 新 手机
我 吃 了 一个 苹果
```

两个“苹果”会共用同一个向量。ELMo、BERT、GPT 等上下文化模型让词表示依赖整句上下文：

$$
z_t=f(w_1,\ldots,w_t,\ldots,w_n)
$$

于是同一个词在不同句子中可以得到不同表示。

### 5. 长距离上下文：RNN/Transformer

固定窗口只看局部。若实体、指代或主题线索跨越很远，CBOW/Skip-Gram 很难处理。RNN 用状态递推累积历史，Transformer 用自注意力直接建立任意位置之间的联系。这也是从第 2 讲自然过渡到第 5 讲的关键。

## 演进图

```text
one-hot
  |
  v
CBOW / Skip-Gram
  |-- negative sampling / hierarchical softmax：让训练可扩展
  |-- subsampling / reweighting：让训练不被高频词淹没
  |-- subword：让模型处理 OOV 和形态信息
  v
GloVe / matrix factorization：显式利用全局共现统计
  v
ELMo / BERT / GPT：同一个词在不同上下文中产生不同表示
```

## 本质判断

CBOW/Skip-Gram 的问题不是“太简单所以没用”，而是它们把语义假设压缩得太狠：词被视为静态点，语境被压成固定窗口，句法顺序被弱化。解决方向应沿着三个维度推进：

- 从局部共现到全局统计。
- 从词级原子到子词组合。
- 从静态词向量到上下文化表示。

这条线索也解释了为什么后续序列标注任务不能只靠词向量本身，而必须引入 RNN、CRF 或 Transformer 来建模上下文结构。
